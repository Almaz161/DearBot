# DearBot — гайд для стримера

Полная установка с нуля занимает ~10 минут. Никакого кода, всё через формы и кнопки.

---

## Что ты получишь

- Все активации Channel Points (твоих наград) пишутся в Google Sheets — ник, награда, текст комментария, дата.
- Зрители заказывают музыку через награду или `!sr <название>` — бот ищет видео на YouTube и проигрывает в OBS.
- Команды модераторам: `!skip`, `!queue`, `!pause`, `!resume`, `!volume 50`, `!clearqueue`.

---

## Шаг 1. Запусти бота на Railway (бесплатно)

Бот живёт в облаке Railway — твой компьютер можно выключать, бот продолжит работать.

1. Зайди на [railway.app](https://railway.app) и зарегистрируйся через GitHub.
2. Открой репозиторий: <https://github.com/Almaz161/DearBot>. Нажми **Fork** в правом верхнем углу — у тебя появится своя копия.
3. В Railway: **New Project → Deploy from GitHub repo** → выбери свой форк `DearBot`. Если он не виден — нажми **Configure GitHub App** и дай Railway доступ к репозиторию.
4. Railway сам соберёт Docker-образ и поднимет бота. Это займёт 2-3 минуты.
5. В настройках сервиса (вкладка **Settings**):
   - **Networking** → нажми **Generate Domain**. Получишь публичный URL вида `https://dearbot-production-xxxx.up.railway.app` — сохрани.
   - **Volumes** → **New Volume**, mount path: `/app/data`, размер: 1 GB. Это нужно, чтобы токены и логи не пропадали при перезапуске.
6. Открой свой URL в браузере — должна открыться страница **DearBot — Настройка**.

> Если Railway просит карту: на старте они дают $5 кредитов в месяц бесплатно, для одного бота этого хватает с большим запасом.

## Шаг 2. Создай Twitch-приложение (2 минуты, разовая операция)

Нужно, чтобы бот мог писать в твой чат и читать награды. У Twitch это бесплатно, кредитка не нужна.

1. Залогинься в [dev.twitch.tv/console/apps/create](https://dev.twitch.tv/console/apps/create) под своим основным Twitch-аккаунтом.
2. **Если Twitch требует включить 2FA** — включи (Settings → Security & Privacy → Set up Two-Factor Authentication). Без этого создавать приложения нельзя.
3. Заполни:
   - **Name**: например `DearBot` (никто не увидит, кроме тебя).
   - **OAuth Redirect URLs**: вернись в визард бота — там есть готовая ссылка с кнопкой **Copy**. Вставь её сюда.
   - **Category**: `Chat Bot`.
   - **Client Type**: `Confidential`.
4. Нажми **Create**.
5. На странице приложения:
   - Скопируй **Client ID**.
   - Нажми **New Secret**, скопируй **Client Secret** (показывается один раз — не закрывай вкладку, пока не вставишь в визард).

---

## Шаг 3. Введи Client ID и Secret в визарде

1. Вернись на страницу бота (`https://твой-railway-url/setup`).
2. Вставь Client ID и Client Secret в форму на шаге 1.
3. Поле «Логин аккаунта-бота» — оставь пустым (бот будет писать от твоего имени). Если хочешь отдельный аккаунт-бот, заведи второй Twitch-аккаунт, добавь его в свои модераторы, и впиши его логин здесь.
4. Жми **Сохранить и продолжить**.

---

## Шаг 4. Войди через Twitch

1. На шаге 2 нажми **Войти как стример**.
2. Откроется окно Twitch — нажми **Authorize**.
3. Окно закроется само. На странице визарда увидишь твой Twitch ID в строке «Авторизованы».

Если используешь отдельный аккаунт-бот:
- Зайди в Twitch под аккаунтом-ботом во второй вкладке (или приватном окне).
- На странице визарда нажми **Войти как бот-аккаунт**.
- Авторизуй.

---

## Шаг 5. Выбери награды

1. Список твоих Channel Points-наград загрузится автоматически. Если список пустой — создай награды в [Creator Dashboard → Channel Points](https://dashboard.twitch.tv/community/channel-points/rewards), потом нажми **Обновить список**.
2. На наградах, которые хочешь записывать в Google Sheets, нажми зелёную кнопку **Лог**.
3. На одной награде (предполагается «Заказать песню» или похожее) нажми фиолетовую **Музыка**. У этой награды **обязательно** должна быть включена опция *"Require viewer to enter text"* в Twitch — иначе боту нечего искать.
4. Жми **Сохранить**.

---

## Шаг 6. Google Sheets (опционально)

Если хочешь, чтобы активации сохранялись в Google-таблице:

1. Создай новую Google-таблицу: <https://sheets.new>.
2. **Extensions → Apps Script**, удали всё содержимое, вставь:

```javascript
function doPost(e) {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
  const data = JSON.parse(e.postData.contents);
  sheet.appendRow([
    new Date(data.redeemed_at),
    data.reward_title,
    data.user_display || data.user_login,
    data.user_input || ""
  ]);
  return ContentService.createTextOutput(JSON.stringify({ ok: true }));
}
```

3. Сохрани (Ctrl+S). Назови проект как хочешь.
4. **Deploy → New deployment** → шестерёнка → **Web app**.
   - **Execute as**: Me
   - **Who has access**: **Anyone** ← ВАЖНО, иначе бот не сможет писать.
5. Нажми **Deploy**, разреши доступ, скопируй **Web app URL**.
6. На шаге 4 в визарде бота вставь этот URL и нажми **Сохранить**.

---

## Шаг 7. Добавь оверлей в OBS

1. На шаге 5 в визарде есть готовая ссылка вида `https://твой-railway-url/overlay?token=...`. Нажми **Copy**.
2. В OBS: **Sources → +** → **Browser** (Браузер).
3. **URL**: вставь скопированную ссылку.
4. **Width × Height**: `1920 × 1080`.
5. ⚠ **Поставь галку "Control audio via OBS"** (Управлять аудио через OBS) — иначе зрители не услышат музыку.
6. Нажми **OK**.

---

## Шаг 8. Запусти бота

В визарде нажми **Готово, запускаем бота**. Railway перезапустится автоматически (15-20 секунд). Бот подключится к твоему чату и начнёт слушать награды.

Чтобы проверить, что всё работает:
- Активируй награду «Музыка» с текстом песни — в OBS появится плеер.
- Активируй любую залогированную награду — открой свою Google-таблицу, там появится строка.
- Напиши в чат `!sr Король и Шут — Лесник` — бот добавит трек в очередь.

## Если что-то не работает

- **OAuth не редиректит обратно**: проверь, что **OAuth Redirect URL** в Twitch-приложении совпадает с тем, что показал визард (включая `https://` и `/setup/oauth/callback`). Любая разница в одном символе ломает редирект.
- **Список наград пустой**: создай Channel Points-награды в Creator Dashboard. Channel Points доступны только Affiliate/Partner — если у тебя ещё нет этого статуса, награды не работают.
- **Плеер в OBS не играет**: проверь галку **Control audio via OBS**. Если всё равно нет звука — открой OBS Mixer и убедись, что источник Browser не замьючен.
- **Бот не отвечает на `!sr`**: подожди 30 секунд после перезапуска. Если всё равно молчит — в Railway открой **Deployments → Logs** и поищи `chat connected as ...`. Если такой строки нет, токены сломались — заново пройди шаг 4 в визарде.
- **Railway бесплатные кредиты закончились**: можно перенести на [Render.com](https://render.com) (тоже бесплатно) или [Fly.io](https://fly.io). Все три поддерживают наш Dockerfile из коробки.

## Безопасность

- **Client Secret** хранится у Railway в переменных окружения **и** в `data/config.json` на volume. Никому его не показывай, в стрим случайно не транслируй.
- **OBS URL** содержит токен в query — если кто-то узнает URL, он увидит твою очередь и сможет крутить треки. Не публикуй его в чате/Discord.
- **Бот пишет в чат от твоего аккаунта** — если используешь отдельный бот-аккаунт, давай ему минимум прав (модератор достаточно).

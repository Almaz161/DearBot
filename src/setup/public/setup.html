DearBot — Настройка

Один раз пройди мастер, и бот заработает.

1 Создай Twitch-приложение

У бота должно быть собственное Twitch-приложение, чтобы он мог писать в чат и читать награды. Это бесплатно.

  1. Открой Register Your Application
  2. Заполни форму:
    • Name: например DearBot
    • OAuth Redirect URLs: вставь точно эту ссылку (нажми «Copy» ниже):
    • Category: Chat Bot
    • Client Type: Confidential
  3. Жми Create, на странице приложения скопируй Client ID, потом нажми New Secret и скопируй Client Secret.

2 Войди через Twitch

Откроется вкладка Twitch — нажми Authorize. Если бот должен писать от отдельного аккаунта-бота, перед нажатием обязательно залогинься в Twitch под нужным аккаунтом.

Авторизованы: никто

3 Награды Channel Points

Список загрузится с твоего канала. Поставь зелёную галку «Лог» на наградах, которые хочешь записывать. Фиолетовая «Музыка» — на одной награде (текст из её комментария будет считаться запросом песни).

4 Google Sheets (опционально)

Бот может писать каждую активацию награды в твою Google-таблицу. Полная инструкция со скриптом — в README.

5 OBS Browser Source

Добавь этот URL в OBS как Browser Source (Source → Browser). Поставь галку «Control audio via OBS» — иначе зрители не услышат музыку.

Размер: 1920×1080.

Настройка завершена. Бот сейчас перезапустится — после перезапуска он подключится к Twitch и начнёт работать. На локальной машине, возможно, придётся вручную запустить npm run dev ещё раз; на Railway/Docker всё автоматически.

Если у вкладок OAuth не закрылись автоматически — закрой их руками и обнови эту страницу.
